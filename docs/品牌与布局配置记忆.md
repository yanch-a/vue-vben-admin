## 0. 整体 UI 默认配置改哪里？（最常用）

**本项目唯一推荐入口：**

`apps/web-ele/src/preferences.ts`

用 `defineOverridesPreferences({ ... })` **只覆盖你要改的项**，其余自动继承框架默认。


| 层级              | 文件                                                  | 何时改                    |
| --------------- | --------------------------------------------------- | ---------------------- |
| **项目覆盖（优先改这里）** | `apps/web-ele/src/preferences.ts`                   | 改默认布局、主题、顶栏、侧栏、标签栏、版权等 |
| 框架全局默认（勿轻易动）    | `packages/@core/preferences/src/config.ts`          | 看全部可配字段清单；尽量不要直接改框架    |
| 类型定义            | `packages/@core/preferences/src/types.ts`           | 查某个 key 的合法取值          |
| 运行时读取           | `packages/@core/preferences/src/use-preferences.ts` | 组件里判断当前布局/主题           |


### 改完不生效？

1. 清空站点 LocalStorage（偏好会缓存；同 `VITE_APP_NAMESPACE` 下旧值会盖住 `preferences.ts`）
2. 硬刷新浏览器
3. 确认 `.env` 里 `VITE_APP_NAMESPACE`（当前多为 `lemon-web-ele`）

### 常用可覆盖字段速查（写在 `preferences.ts` 里）

```ts
export const overridesPreferences = defineOverridesPreferences({
  app: {
    layout: 'sidebar-mixed-nav', // 布局：见下方 layout 枚举
    authPageLayout: 'panel-right', // 登录页表单位置
    defaultHomePath: '/dashboard', // 无菜单时兜底首页
    locale: 'zh-CN',
    colorWeakMode: false,
    compact: false,
    // ...
  },
  theme: {
    mode: 'light', // light | dark | auto
    colorPrimary: 'hsl(212 100% 45%)',
    radius: '0.5',
    fontSize: 16,
    semiDarkSidebar: false,
  },
  sidebar: {
    width: 224,
    collapsed: false,
    collapsedShowTitle: false,
  },
  header: {
    enable: true,
    height: 50,
    mode: 'fixed',
  },
  tabbar: {
    enable: true,
    keepAlive: false,
    styleType: 'chrome',
  },
  breadcrumb: { enable: true, showIcon: true },
  footer: { enable: false },
  logo: { enable: true, source: '/logo.png', showText: true },
  copyright: { enable: true, companyName: 'Lemon', icp: '' },
  navigation: { accordion: true, styleType: 'rounded' },
  transition: { enable: false },
  widget: { /* 顶栏按钮显隐与顺序 */ },
  shortcutKeys: { globalLockScreen: false },

```

### `app.layout` 可选值


| 值                    | 含义（偏好面板文案）        |
| -------------------- | ----------------- |
| `sidebar-nav`        | 侧边单列菜单            |
| `sidebar-mixed-nav`  | **双列菜单**（本项目当前默认） |
| `header-nav`         | 顶部菜单              |
| `mixed-nav`          | 侧边 + 顶部混合         |
| `full-content`       | 内容全屏              |
| `header-sidebar-nav` | 顶栏 + 侧栏           |


界面入口：登录后右上角 **偏好设置 → 布局**。

### 相关文件

`apps/web-ele/src/api/system/systemSetting.ts`

## 3. 「默认布局改成双列菜单」改哪里？

**答案：双列菜单 = `sidebar-mixed-nav`（偏好文案 key：`preferences.twoColumn`）。**


| 层级              | 位置                                                                                      |
| --------------- | --------------------------------------------------------------------------------------- |
| **本项目默认（你要改的）** | `apps/web-ele/src/preferences.ts` → `app.layout: 'sidebar-mixed-nav'`                   |
| 框架全局默认          | `packages/@core/preferences/src/config.ts` → `app.layout`（默认是 `sidebar-nav` 单列，不要轻易改框架） |
| 偏好设置面板 UI       | `packages/effects/layouts/src/widgets/preferences/blocks/layout/layout.vue`             |
| 运行时判断           | `packages/@core/preferences/src/use-preferences.ts`（`isSidebarMixedNav`）                |


界面入口：登录后右上角 **偏好设置 → 布局 → 双列菜单**。

## 4. 「登录页右上角布局切换」改哪里？

登录页右上角工具条里的「左 / 中 / 右」切换，控制的是 `**preferences.app.authPageLayout`**。


| 层级           | 位置                                                                           |
| ------------ | ---------------------------------------------------------------------------- |
| **切换组件（核心）** | `packages/effects/layouts/src/widgets/layout-toggle.vue`                     |
| 工具条挂载        | `packages/effects/layouts/src/authentication/toolbar.vue`（含 `layout` 项）      |
| 认证大布局        | `packages/effects/layouts/src/authentication/authentication.vue`             |
| 本项目默认值       | `apps/web-ele/src/preferences.ts` → `app.authPageLayout: 'panel-right'`      |
| 框架默认         | `packages/@core/preferences/src/config.ts` → `authPageLayout: 'panel-right'` |


可选值：

- `panel-left` 表单居左  
- `panel-center` 表单居中  
- `panel-right` 表单居右

若要隐藏登录页右上角布局按钮：改 `authentication.vue` / `auth.vue` 的 `toolbarList`，去掉 `'layout'`。

## 6. 常见排查

1. **改了 SQL / 后台保存，登录页没变**
  - 看接口 `GET /lemon/system/systemSetting/brandConfig` 是否返回 `ui.brand.`*  
  - 确认 `type=1` 且编码前缀正确
2. **布局仍是单列 / 改了 preferences 不生效**
  - **先清 LocalStorage 偏好缓存**  
  - 查 `preferences.ts` 的 `layout`  
  - `.env` 的 `VITE_APP_NAMESPACE` 是否仍是旧值
3. **背景图 404**
  - 确认 `apps/web-ele/public/login-bg.png` 存在，或后台上传了可访问 URL
4. **菜单里没有「系统展示配置」**
  - 执行 `ui_brand_sys_menu.sql`，或在菜单管理手工加  
   `component=/setting/systemSetting/index`
5. **想看全部可配项**
  - 打开 `packages/@core/preferences/src/config.ts` 对照复制到 `preferences.ts` 覆盖

## 7. 一句话速记

- **整体 UI 默认（布局/主题/侧栏/标签栏…）**：`apps/web-ele/src/preferences.ts`  
- **全量字段清单**：`packages/@core/preferences/src/config.ts`  
- **品牌文案/图**：后台 `sys_setting` + 前端 `store/branding.ts`  
- **双列菜单默认**：`preferences.ts` → `layout: 'sidebar-mixed-nav'`  
- **登录页右上角布局**：`layout-toggle.vue` + `authPageLayout`  
- **改完要清 LocalStorage**，否则缓存盖住默认值
